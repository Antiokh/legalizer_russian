# legalizer_russian

Профессиональный русскоязычный редактор и линтер для юридических и официально-деловых документов.

Проект вырос из экспериментального legal-document слоя `Antiokh/humanizer_russian` и вынесен отдельно, потому что профессиональная юридическая читаемость местами требует правил, прямо противоположных обычной редакторской «естественности»: стабильного повтора терминов, допустимых клише, формальной модальности и жанрово-зависимой композиции.

## Принцип

Сначала определить тип документа и применимую систему источников, затем собрать активный набор правил. Правила могут включать, отключать, понижать или переопределять другие правила в зависимости от профиля.

## Профили

- `official-admin` — письма, записки, справки, акты, протоколы, приказы;
- `normative` — положения, правила, инструкции, регламенты, локальные нормативные акты;
- `normative/legislation` — законопроектная юридическая техника;
- `contractual` — договоры, соглашения, приложения;
- `legal-procedural` — претензии, иски, отзывы, ходатайства и другие процессуальные документы.

## Архитектура

```text
core/                 resolver и общие инварианты
profiles/             включение/отключение/переопределение правил по жанрам
rules/                атомарные правила
references/           компактный рабочий контекст
studies/              исследования нормативных источников и книг
evals/                собственные тестовые случаи
docs/                 архитектура, источники и политика проекта
```

## Приоритет источников

В пределах одной применимой юрисдикции и даты:

1. действующая обязательная норма;
2. применимый действующий национальный стандарт;
3. официальные методические рекомендации;
4. специальная литература по юридическому письму и делопроизводству;
5. проектная эвристика.

Статус источника всегда хранится отдельно от силы конкретного правила.
